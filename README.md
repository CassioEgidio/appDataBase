# 📱 appDataBase

Aplicativo desenvolvido em **Kotlin** utilizando o **Android Studio**, criado durante as aulas da disciplina de **Programação Mobile**.

## 📌 Descrição

Este aplicativo foi desenvolvido com o objetivo de aplicar, na prática, os conceitos estudados em sala de aula, como:
- Desenvolvimento de aplicativos Android
- Utilização da linguagem Kotlin
- Estrutura de projetos no Android Studio
- Manipulação de dados e persistência local

## 🛠️ Tecnologias Utilizadas

- Kotlin
- Android Studio
- Gradle
- Banco de dados local utilizando Room (SQLite)

## 🎓 Contexto Acadêmico

- **Curso:** Desenvolvimento de Sistemas
- **Disciplina:** Programação Mobile
- **Instituição:** ETEC

## 🚀 Finalidade

Projeto desenvolvido com fins **educacionais**, voltado ao aprendizado de desenvolvimento de aplicativos Android utilizando Kotlin.
